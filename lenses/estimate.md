# Lens: estimate

**Question.** Can the remaining work finish sooner, or with less, than the estimate says?

**Read first.** The saved estimate your brief names (what remains, the critical path, the end time), then the session's plan.

**Checklist.** Answer each with a change (the block, the agent, the minutes it saves and the measured figure behind them) or with "no change" and the measured reason.

1. Can the block that dominates the critical path start earlier, or be cut by file into two agents?
2. Which block waits on a block it does not depend on? For each `waits` line, as your brief pastes them: which agent's file or contract does it need, and which part needs neither?
3. Which block is the coordinator's own serial work, and which part of it can an agent or a script do?
4. Which run or check repeats one that already proved the same thing?
5. Which agent is larger than its question, or holds so much context that its next rows cost less in a fresh agent?
6. Where does the result rest on one reader or one kind of evidence, and what would a second lens cost?
7. What waits on the project's owner, and what can be prepared so that the answer is one choice?

Record as a finding each figure with no source, and each estimate naming no measured figure it scales from.

**Not its business.** Whether the planned work should be done (`essential`), or is correct.

**Silent.** No: a late end time is seen, though only once it is late.

**Applies.** on request.

**Run by.** auditor.
