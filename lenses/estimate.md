# Lens: estimate

**Question.** Can the remaining work finish sooner, or with less, than the estimate says?

**Read first.** The saved estimate your brief names (what remains, the critical path, the end time), then the session's plan.

**Checklist.** Answer each with a change (the block, the agent, the minutes it saves and the measured figure behind them) or with "no change" and the measured reason. Mark each change that would lower a review, a check or a reading, which only the owner rules.

1. Timing: can the block that dominates the critical path start earlier, and which steps of the ending, such as the evaluation's set-up, the changelog and the handoff's draft, can be staged during the review?
2. Waits: which block waits on a block it does not depend on? For each `waits` line, as your brief pastes them: which agent's file or contract does it need, and which part needs neither?
3. Scoping: can the dominating block be cut by file into two agents, and which edge would a hunk or a first commit remove, as for slices that only add a catalogue's keys?
4. Batching: which small edits could go to one agent, which landings could share one push, and which readers could run in parallel?
5. Which block is the coordinator's own serial work, and which part of it can an agent or a script do?
6. Repeats: which run or check repeats one that already proved the same thing?
7. Context: which agent is larger than its question, or holds so much context that its next rows cost less in a fresh agent?
8. Owner waits: what waits on the project's owner, and what can be prepared so that the answer is one choice?
9. What other change of any kind would end the work sooner or spend less?
10. Where does the result rest on one reader or one kind of evidence, and what would a second lens cost?

Record as a finding each figure with no source, and each estimate naming no measured figure it scales from.

**Not its business.** Whether the planned work should be done (`essential`), or is correct.

**Silent.** No: a late end time is seen, though only once it is late.

**Applies.** on request.

**Run by.** auditor.
