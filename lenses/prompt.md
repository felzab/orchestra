# Lens: prompt

**Question.** Will a model holding only this page do the right thing? A model acts on a misread rule without asking, so the page is tested on a reader with no context, as Anthropic's prompting guide says.

**Read first.** The project's writing rules, each changed page whole, then the pages and commands it names.

**Checklist.**

1. Is each rule stated as what to do, with its reason in a clause?
2. Does each term name one thing, as sibling pages use it?
3. Is each command spelled as the program accepts it?
4. Each figure the model will act on: does it carry its source, and does the source still give it?
5. Does each conditional rule name a predicate the model can observe?
6. Is anything said twice, here or on a page this one could name?
7. Does it repeat a rule a hook or a tool's message enforces?
8. Does it contradict a sibling page or the code?
9. Which step would a model resumed from a compaction's summary alone get wrong?
10. Is emphasis kept for what a hook also holds, since it makes a model over-apply a rule?
11. Which bytes paid at each load would no reader miss?
12. Is what only a run shows, whether a model follows the page, left to `use`?

**Not its business.** Pages a person reads (`document`), the design it describes.

**Silent.** Yes: a model follows a wrong page, and nothing fails.

**Applies.** paths `**/skills/**/*.md`, `**/agents/**/*.md`, `**/commands/**/*.md`, `**/.claude/**/*.md`, `**/CLAUDE.md`, `**/AGENTS.md`.

**Run by.** auditor.
