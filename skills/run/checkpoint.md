# The checkpoint

Run at each wave's end, once its branches have landed and, where the clone has a remote, its push is made, and whenever the turn-end hook says it is due, since a fleet that dispatches as work frees has no clean wave end.

1. **Nothing left behind.** In `orchestra status`, no report waits to be judged, and each judged writer has landed or `orchestra log` says why it has not.
2. **Drift.** The same output names each file changed that no landed brief or ticked slice owns and each agent on no slice, and lists as `planned` each unticked slice no agent took. Repair each drift line, or write it into `PLAN.md` as a decision with its reason.
3. **Findings.** `orchestra findings` lists every unclosed row by owner. Each is with a running agent or on a queue; a row owed to a brief not yet written waits on the queue `ending` until that brief's dispatch routes it. `orchestra route ending <NAME>-F1` takes one back from an agent that finished without closing it. Ask each row on the queue `owner` that no question carries yet, those of one subject as one question.
4. **Trees.** `orchestra prune` removes the worktree and branch of each agent with nothing unlanded and its report judged, and keeps one whose report waits. Judge the reason it prints for each tree it keeps.
5. **The plan.** Tick the landed slices in `PLAN.md` and write in what this wave taught about the next.
6. **The estimate.** Read [the estimate's steps](../estimate/SKILL.md) and run steps 1 to 4 and 7 from `orchestra status --measure` every time, since the turn-end hook reads landings and judged reports from the newest saved estimate. Run steps 5 and 6 where step 4 gave a change, and step 8 at the two moments it names.
7. **Now.** Rewrite `NOW.md` under its two labels.

Reply with what landed, what drifted, what is next, and what waits on the owner or that nothing does. At a seam, a wave's end or any checkpoint after a prompt has said the context nears its window, the state holds all in flight, so compacting loses least: call `mcp__orchestra__compact` and end the turn, away or not; lacking it, suggest an attended owner type `/compact`.
