# Security policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.4.x   | Yes       |
| 0.3.x   | No        |
| 0.2.x   | No        |
| 0.1.x   | No        |

## Reporting a vulnerability

Report a vulnerability privately, through GitHub's private vulnerability reporting, and never in a
public issue, pull request or discussion:

1. On the repository's main page, open the **Security and quality** tab.
2. Click **Report a vulnerability**.
3. Fill in the form and click **Submit report**.

## What to expect

GitHub notifies the maintainers and adds you as a collaborator on the proposed security advisory
the report opens. The maintainers answer there, and the advisory stays private while a fix is
prepared. The fix ships in a new release, and the advisory is then published with you credited.
